# Income Site — лендинг для продажи цифрового набора

Готовый статический сайт лежит в этой папке. Он продаёт цифровой продукт `product/` ("Стартовый набор фрилансера"). 

## Что уже подключено в коде

- Лендинг: `index.html`, `styles.css`, `script.js`
- Кнопки покупки: все элементы с `data-payment` вызывают оплату через `PAYMENT_LINK` в `script.js`
- Контакты: `CONTACT_EMAIL` и `TELEGRAM_LINK` в `script.js`
- SEO-база: title, description, Open Graph, адаптивная верстка
- Цифровой продукт для продажи: папка `product/`

## 1) Что нужно для монетизации

### A. Выберите платформу приёма оплаты

| Вариант | Для кого | Что нужно | Стоимость старта |
|---|---|---|---|
| **Boosty / Hipolink** | РФ/СНГ, проще всего | Аккаунт, подтверждение, карточка/счёт для вывода | Бесплатно, комиссия с продаж |
| **Gumroad** | Международно | Аккаунт, email, настройки выплат | Бесплатно, комиссия с продаж |
| **Stripe Payment Link** | Международно, если доступен | Аккаунт Stripe, верификация, банк | Бесплатно, комиссия с транзакций |
| **ЮKassa / Robokassa** | РФ, юрлицо/ИП/самозанятый по условиям | Регистрация, проверка, договор/анкета | Обычно без абонентки, комиссия с платежей |

> Перед выбором проверьте актуальные условия, комиссии и требования к статусу (физлицо/самозанятый/ИП) на сайте платформы.

### B. Подготовьте продукт к выдаче после оплаты

1. Упакуйте папку `product/` в ZIP-архив.
2. Загрузите ZIP в выбранную платформу как цифровой товар/файл после оплаты.
3. Создайте страницу оплаты/товара.
4. Скопируйте ссылку на оплату.

### C. Подключите ссылку к сайту

Откройте `script.js` и заполните:

```js
const PAYMENT_LINK = "https://..."; // ваша ссылка на оплату
const CONTACT_EMAIL = "you@example.com";
const TELEGRAM_LINK = "https://t.me/yourchannel";
```

### D. Юридические/налоговые basics

- Укажите реальный статус продавца и способ легальной работы с доходом (самозанятость/ИП/юрлицо — по вашей ситуации).
- Добавьте оферту/политику обработки данных, если собираете персональные данные или работаете по требованиям платформы.
- Не обещайте гарантированный доход покупателям. Шаблон чек-листа в продукте — не юридическая консультация.

## 2) Как бесплатно опубликовать сайт

### Вариант 1: Netlify Drop (самый быстрый)
1. Зайдите на Netlify.
2. Перетащите папку `income-site` в Netlify Drop.
3. Получите бесплатный URL вида `https://...netlify.app`.

### Вариант 2: GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите содержимое папки `income-site`.
3. В Settings → Pages включите публикацию из ветки `main`.
4. Получите URL GitHub Pages.

### Вариант 3: Cloudflare Pages
1. Подключите репозиторий или загрузите проект.
2. Укажите папку публикации как корень сайта.
3. Получите бесплатный URL.

## 3) Как раскрутить бесплатно

### Первые 7 дней
- **День 1:** Опубликуйте сайт, проверьте кнопку оплаты, добавьте ссылку в профиль/био.
- **День 2:** Сделайте пост-проблему: "почему фрилансеры теряют деньги на хаосе".
- **День 3:** Покажите фрагмент шаблона (скрин/пример) и пользу.
- **День 4:** Опубликуйте кейс/сценарий: "как бриф экономит переделки".
- **День 5:** Сделайте FAQ-пост: кому подходит, что внутри, как получить.
- **День 6:** Соберите обратную связь у знакомых/коллег, поправьте оффер.
- **День 7:** Повторите лучший пост в другом формате (Reels/сторис/карточка).

### Каналы без бюджета
- **Telegram:** личный канал/чат, полезные посты + мягкий CTA на лендинг.
- **VK:** посты, клипы, сообщества по фрилансу/малому бизнесу (где разрешено).
- **YouTube Shorts/Reels/TikTok:** короткие демонстрации "до/после", разбор шаблонов.
- **Профильные чаты/форумы:** отвечайте по делу, не спамьте; оставляйте ссылку где уместно.
- **Партнерства:** предложите блогерам/каналам партнерскую комиссию за продажу.

### Что отслеживать
- Кликов по кнопке покупки (можно подключить бесплатную аналитику позже).
- Количество переходов на страницу оплаты.
- Конверсию: переходы → покупки.
- Какие посты приводят трафик — делайте больше такого.

## 4) Быстрые улучшения после запуска

- Добавить реальные отзывы/кейсы.
- Сделать бесплатный мини-шаблон в обмен на email/подписку.
- Подключить аналитику (Google Analytics, Yandex Metrica — бесплатно).
- Протестировать 2-3 варианта заголовка и цены.
- Добавить OG-изображение `og-image.png` для красивого превью в соцсетях.
